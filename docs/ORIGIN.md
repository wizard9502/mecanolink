# Origine du projet

- Lien fourni : `https://share.gemini.google/EDURmLhGQbvG`
- Titre récupéré via les métadonnées publiques du lien : **« Application Pièces Auto »** (Créé avec Gemini).
- Aperçu (`og:image`) : maquette mobile sombre/orange pour le marché sénégalais / Afrique de l'Ouest, avec :
  - en-tête MecanoLink/FadjiAuto, localisation, FR, SOS 24/7, favoris, panier ;
  - véhicule Toyota Hilux 2020, spec « Golfe / Afrique », 2.4L D-4D 4x4, DK-4821-AM, 84 500 km ;
  - recherche « 200 pièces, réf OEM, 77 marques » + bouton VIN / IA ;
  - filtres Freinage, Filtration & Huile, Suspension & Train, Moteur & Injection ;
  - badges 77 MARQUES, 200 Pièces HD, GPS & Mobile Money ;
  - navigation Accueil / Catalogue / Garage / Commandes / Profil.
- Le code source de la maquette n'était pas accessible sans connexion Google ; MecanoLink est donc une **reconstruction fonctionnelle**, pas une modification du fichier d'origine.
- Tous les prix, références, garages et numéros de téléphone sont inventés pour la démo.
